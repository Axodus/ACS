# EPIC-11 Milestone C — Composition Surface

## Goal

The user can compose an Agent correctly from governed resources.

## Scope

- roles
- profiles
- capabilities
- skills
- tools
- plugins
- engines
- providers
- models

## Requests

- CS-01 Role & Profile Composition
- CS-02 Capability Model
- CS-03 Skills Management
- CS-04 Tools & Plugins Management
- CS-05 Models, Engines & Providers

## Dependencies

- Agent Lifecycle
- governed resource registries
- Product API composition endpoints

## Success criteria

- the surface explains why an Agent has its current capabilities
- missing dependencies and compatibility conflicts are visible
- composition changes remain revisioned and auditable
