- local Playwright is the primary product gate; Vercel exact-SHA verification is secondary.

## S04 remediation contract

Supported actions:

- `RETRY_RECONCILIATION` — reuses `EconomicService.reconcile()` then reevaluates the proven mismatch;
- `REEVALUATE_MISMATCH` — reruns current usage/settlement/receipt evidence;
- `MARK_NO_ACTION` — governed reject with required justification.

Unsupported / REQUIRES_FUTURE_POLICY:

- `RETRY_SETTLEMENT`
- `REFRESH_PROVIDER_EVIDENCE`
- `RESOLVE_WITH_EVIDENCE` as a direct value mutation

Governance reuses `economic.remediate`. Idempotency is `tenant + exception + action + idempotencyKey`. Failure preserves original exception/mismatch evidence. Closed exceptions cannot be remediated.

Environment caveat: local `dist/` remains EROFS; TypeScript emit is validated to a writable outDir.
