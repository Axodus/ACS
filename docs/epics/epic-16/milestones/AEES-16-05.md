# AEES-16-05 — Provider Boundary & Capability Contract

Status: IN PROGRESS
Type: execution + acceptance
Canonical UI: .design/app-standalone
/static: forbidden

AEES-16-05 S01 defines the canonical provider boundary for ACS production financial operations. AEES-16-05 S02 turns that boundary into evidence-based diagnostics and readiness truth, and S03 hardens degraded/outage semantics without introducing broad provider orchestration.

## Canonical environment/provider topology

| Environment | Dispatch | OpenClaw Worker | Provider boundary |
| --- | --- | --- | --- |
| LOCAL | local | OpenClaw Worker — Local | localhost and local providers are allowed |
| DEVELOPMENT | remote | OpenClaw Worker — Cloud | Vercel acs-app + Railway Product API + Cloud worker |
| PRODUCTION | remote | OpenClaw Worker — Remote VM | dedicated services / VMs + durable providers |
