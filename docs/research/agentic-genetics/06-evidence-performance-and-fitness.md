# Evidence, performance and fitness

> **NON-NORMATIVE / RESEARCH ONLY**
>
> This research does not authorize NFTs, smart contracts, tokenization, Marketplace functionality, royalties, economic rights, reputation authority, or changes to EPIC-17.
>
> Any transition requires: CEO decision -> CTO architecture / feasibility authorization -> separate REQ -> implementation authorization.

## Required distinction

```text
observed performance != universal fitness != reputation != authority
```

Evidence may be associated with the exact Agent, exact Agent revision, claimed Genome revision, task/workload, environment, time window, method, evaluator, source, and verification state. It remains proof owned by its existing owner; it does not become a universal Genome score.

## Comparability questions

| Concern | Why it matters |
| --- | --- |
| workload/domain and execution context | outcomes across different tasks are not interchangeable |
| sample size and completeness | small or selected samples can mislead |
| metric and method version | a number is uninterpretable without calculation rules |
| temporal relevance | observed behavior can become stale |
| evaluator independence | self-evaluation and collusion require disclosure |
| selective disclosure | favorable evidence can hide failures |
| provenance and verification | fabricated records must remain distinguishable |

## Genome Fitness

“Genome Fitness” may be explored only as an **OPEN QUESTION**. Any future concept would need a scoped claim, declared methodology, uncertainty, source Evidence, anti-gaming controls, expiration, and a prohibition on inferring authority. No canonical formula, ranking, admission criterion, or economic valuation is authorized.

## Current Axodus fact

REQ-11 permits bounded Evidence-backed historical performance views only with explicit method, window, completeness, mode, and source. It rejects fitness, reputation, rank, authority, and economic-right claims. See [performance boundary](../../epics/epic-17/req-11/performance-and-derived-views.md).
