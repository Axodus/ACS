# ACS Judgment Principle

**Classification:** Research finding / non-normative
**Status:** Preserved from `ACS-RESEARCH-POC-01`, closed September 17, 2026

This note records the architectural lesson from the System One investigation. It
does not create an ACS contract, alter canonical ownership, or authorize a
provider integration.

1. Prefer deterministic evaluation when the condition is deterministically
   knowable.
2. Use probabilistic judgment only for genuinely contextual or ambiguous
   assessment.
3. Treat confidence as empirical data requiring calibration, never as authority.
4. Judgment output is advisory.
5. ACS policy owns consequential decisions.
6. Judgment providers must remain replaceable.
7. Evidence is not Judgment, and Judgment is not a Decision.
8. Genome is not Judgment, Reputation, or Economic Value.
