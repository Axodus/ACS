# ACS Trading Ignition Product

# Classification

Trading Ignition is:
- an ACS Product for end-user bot access
- an ACS Service when offered by an enabled DAO Tenant
- an ACS Core monitoring target for risk standards and governance policy

Trading Ignition is not the entire ACS identity.

# Purpose

It helps a certified and licensed Axodus user configure a restricted trading bot with small capital exposure, safe exchange API permissions, guided presets, risk controls, telemetry, and auditable performance records.

---

# Initial User Path

1. Connect wallet.
2. Complete Academy requirements.
3. Complete quizzes and Proof of Knowledge.
4. Earn required `$Neurons`.
5. Acquire the required NFT license through Marketplace.
6. Attach license to the Trading Dashboard.
7. Validate ACS eligibility.
8. Configure exchange API.
9. Pass API safety validation.
10. Select guided risk preset.
11. Start in restricted mode only after `READY`.

---

# MVP Requirements

- wallet dependency
- user readiness checklist
- NFT license validation, mock or real
- API setup guidance
- exchange API connection test
- withdrawal permission rejection
- IP permission/allowlist recommendation in the UI
- basic risk profile selection
- guided bot preset configuration
- emergency stop
- performance dashboard
- logs and event history

---

# Initial Presets

- Conservative: public default; spot-only, no margin, no futures, max $100 capital, max 1x leverage.
- Balanced: only if governance, risk settings, and internal validation allow it.
- Experimental: internal validation only; not available to public users.

---

# Out of Scope

- full multi-agent automation
- public strategy marketplace
- DAO-controlled live parameter changes
- advanced AI recommendations
- compute network integration
- multi-exchange orchestration
- unlimited capital
- aggressive leverage
